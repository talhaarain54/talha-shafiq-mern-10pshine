# 📝 MERN Notes Application

**10P Shine Internship Program**

A full-stack Notes Application built using the MERN stack where users can securely register, log in, and manage their personal notes. Each user can only access their own notes, ensuring privacy and security.

---

## 🔐 Features

### 👤 Authentication

* User Registration
* User Login
* JWT-based Authentication
* Protected Routes

### 📝 Notes Management

* Create Notes
* View All Notes
* Update Notes
* Delete Notes (Soft Delete)

### 🎨 UI Features

* Rich Text Editor (React Quill)
* Dashboard View
* User Profile Page
